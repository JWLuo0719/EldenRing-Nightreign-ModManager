# Nightreign Mod Manager v0.2.0

第二版正式发布，发布日期：2026-08-02。

## 下载文件

- `nightreign-mod-manager_0.2.0_x64-setup.exe`：推荐普通玩家使用。
- `nightreign-mod-manager_0.2.0_x64_zh-CN.msi`：简体中文 MSI 安装包。
- `【双击】--更多游戏内容.url`：指向 `https://link3.cc/voyagekit`，安装后也会出现在管理器程序目录。
- `SHA256SUMS.txt`：发布文件校验值。

## 相比第一版的主要升级

- 启动游戏不再弹出或遗留命令窗口，启动输出统一进入诊断日志。
- 启动前检查会把路径、Steam、残留进程、联机组件、启用 Mod 和冲突拆成玩家能理解的结论，并给出处理方向。
- 界面改用“启动配置、资源型 Mod、功能插件、玩法数据文件、联机一致性清单”等中文说法；原始技术名词收进高级详情。
- 区分正版 Steam、正版 Steam + Seamless、Spacewar + Seamless 和未知混合环境，避免给不同环境套用同一组启动参数。
- 支持作者启动配置的语义保真导入、外部 Mod 失效路径重新定位、玩法数据冲突硬阻止和启动前存档备份。
- 增加服装 Mod 检查：本机与队友视角资源配对、扩展外观 ID 风险、默认停用和方案切换提醒。
- 增加脱敏联机一致性清单，可比较双方完整 Mod 内容、DLL、加载顺序、玩法数据、中文层和 Seamless 设置。
- 暂时隐藏尚未完成发布回归的“应用联机补丁”入口。

## 两组重要 Mod 验证

- More Map Variations + MoreWeapons + 602 简中：在 Spacewar + Seamless 社区路线中完成本机真实启动，确认新增地图/敌人、武器和中文文本生效；服务器登录与 Steam 好友邀请可用。
- Skin Overhaul + 602 服装中文兼容补丁：在 Skin-only + Seamless 方案中确认新增服装模型与中文名称正常显示，服装名称兼容层保留破晓团队来源署名。

这两组方案包含不同的 `regulation.bin`，第二版会阻止直接同时启用。当前没有适配 MMV 2.1.7.1 与 Skin Overhaul 的单一玩法数据合并文件，不能用加载顺序代替合并。

## 验证与边界

- 前端 lint 和生产构建通过。
- Rust 格式、Clippy、check 和测试通过：44 项通过，8 项需要本机真实样本的测试按预期跳过。
- NSIS 与 MSI 均已回读确认：产品版本为 0.2.0，快捷方式位于程序目录且 URL 内容一致。
- 尚未完成第二位玩家实际加入同房后的双人实战，因此不能把“可邀请”表述成“双人联机已验收”。
- 本发布不包含 MMV、MoreWeapons、Skin Overhaul、ME3、SeamlessCoop 或游戏文件。请从原作者页面取得 Mod，并核对版本与授权。
- 安装包尚未进行商业代码签名，Windows 可能显示未知发布者提醒。

## 升级建议

可直接安装第二版覆盖第一版。原有管理器配置保存在用户配置目录；更换玩法 Mod 前仍建议先备份存档，并在启动台运行一次“启动前检查”。
